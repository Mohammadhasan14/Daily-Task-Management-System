**Frontend Running Steps:**

1. To install the dependencies after cloning the repo:
   - Type `cd client-side` then press Enter.
   - Type `npm install` then press Enter.

2. To run the frontend code:
   - Type `npm run dev` then press Enter.

            -------

**Backend Running Steps:**

1. To install the dependencies after cloning the repo:
   - Type `cd server-side` then press Enter.
   - Type `npm install` then press Enter.

2. To run the server code:
   - Type `nodemon index.js` then press Enter.


Then the app should run!
